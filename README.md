# Rural Health Clinic Cost Report Recovery

Maximize defensible all-inclusive-rate reimbursement through visit, cost, productivity, and settlement reconciliation.

**Primary buyer:** Independent and provider-based rural health clinics. **Evidence:** trial balances, visits, provider time, allowable costs, overhead allocations, productivity standards, vaccines, bad debt, interim payments, and cost reports.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Clinic status registry
- Trial balance ingestion
- Visit count validation
- Provider FTE calculation
- Productivity standard analysis
- Allowable cost classification
- Overhead allocation
- Vaccine cost carve-out
- Telehealth treatment
- Bad debt analysis
- Interim rate reconciliation
- AIR calculation
- Cost report schedule generation
- Settlement forecast
- Clinic cost analytics

Run `./start.sh`, then open <http://127.0.0.1:4652>. API: `5652`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
